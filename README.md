### Hi, I'm Harald

Geospatial AI enthusiast with a soft spot for open source. After the startup rollercoaster, I now do applied research in environmental remote sensing at [Joanneum Research](https://www.joanneum.at) in Austria, monitoring the natural environment and describing how it changes with a good mix of Python, deep learning and LLMs. Some of the tools I build along the way end up here as open source.

**Projects**

- [ccdock](https://github.com/hkristen/ccdock): a terminal dashboard for Claude Code sessions over SSH, so you can see what's running and jump back in with one key
- [qgis-arcgis-imageserver-downloader](https://github.com/hkristen/qgis-arcgis-imageserver-downloader): a [QGIS plugin](https://plugins.qgis.org/plugins/arcgis_imageserver_downloader) that downloads large areas from ArcGIS ImageServer REST services at full resolution as Cloud Optimized GeoTIFFs

**Contributions**

- [torchgeo](https://github.com/torchgeo/torchgeo/pulls?q=is%3Apr+author%3Ahkristen+is%3Amerged): the ChangeViT model, multiclass change detection, the OSCD100 dataset and the change detection tutorial, plus a GeoTIFF writer callback and fixes
- [terratorch](https://github.com/torchgeo/terratorch/pull/1134): fixed Clay 1.5 for downstream tasks (segmentation, regression, classification)
- [isaaccorley/skills](https://github.com/isaaccorley/skills/pull/1): `ai-audit`, a Claude Code plugin that flags AI-generated language patterns in academic manuscripts
